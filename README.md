# Computer Space for the Vectrex

A port of Nutting Associates' *Computer Space* (1971) to the Vectrex, in 6809 assembly.

The game rules, timings and artwork come from the gate-level FPGA recreation of the original boards
(Mattias G 2015, DarFPGA 2017), studied in the companion repo
[djmips/computerspace](https://github.com/djmips/computerspace), which runs that core on a Terasic DE1.

## Status

Playable, tested in vecx-run (the drawing methods on a real Vectrex):
the rotated playfield with the original's interlaced star field; the rocket (32 pre-rotated
headings, rotation and thrust as on the original, the engine flame); two saucers with their rotating
light, direction changes and aimed missiles; the steerable rocket missile; box collisions,
explosions, scoring, the 99 timer, hyperspace; raster score digits; PSG sound.
See `docs/spec.md` section 11 for what was decided, what is approximate, and the frame budget.

## Playing

The picture is landscape, like the cabinet's: stand the Vectrex on its side, cartridge side up (as
a 4:3 stand holds it).

Power on: the BIOS title, then attract mode (the saucers fly). Any button starts a game.

| Button | Cabinet control |
|---|---|
| 1 | rotate anticlockwise |
| 2 | rotate clockwise |
| 3 | thrust |
| 4 | fire (hold to refire) |

Score a point by hitting a saucer with your missile (it steers with the rocket); the saucers score
when their missile hits you. A game is 99 time units; finish ahead and you get one more round in
hyperspace (brighter stars, standing in for the original's inverted picture).

## Building

Uses VIDE's own assembler (Asmj) through a vecx-run kit, which bundles it with a build script: set
`VECX_KIT` to the kit's folder. Java 11 or newer.

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

Output: `build\computerspace.bin`, a standard single-bank cartridge of at most 32K, and
`build\computerspace.cnt` (VIDE symbols). The project also opens in the VIDE IDE
(`ComputerSpaceProjectProperty.xml`).

## Running

- **Emulator (headless, with screenshots):**
  `vecx-run.exe --headless --bios skip --seconds 3 --png-at 2.5 build\computerspace.bin`
- **Hardware:** copy `build\computerspace.bin` to a VEXTREME or UVMC2 multicart.

## Spec and tools

`docs/spec.md` is the game specification extracted from the FPGA core, with citations, measurements
and the Vectrex design decisions.

| Path | What |
|---|---|
| `data/stars.txt` | the original star field (375 visible pixels) from a simulation of the core |
| `tools/optstars.py` | picks and orders stars, generates the dot-to-dot drawing code (`--half=0/1` for the interlaced field) |
| `tools/headings.py`, `tools/match.py` | the 32 rocket headings from the core's 4 base images |
| `tools/rocketgen.py` | the ship's 32 headings as segmented dot lists (`rocket.inc`), pre-rotated, plus the engine flame |
| `tools/saucergen.py` | the saucer and its rotating light, 4 phases (`saucer.inc`) |
| `tools/dotlist.py` | the segmented dot-list format shared by both, with its replay self-test |
| `tools/postab.py` | position tables for placing objects on the rotated field (`postab.inc`) |
| `tools/tables.py` | the rocket missile's 16 directions per heading (`tables.inc`) |
| `tools/digits.py` | the 7448 glyphs as raster columns (`digits.inc`) |
| `tools/vxparams.py` | drawing constants shared by the generators |
| `tools/sim/` | GHDL testbench that runs the core with scripted inputs and dumps lit pixels per frame (`run_spec.sh`) |
| `tools/analyse.py` | reads those dumps |

The tools read the core from `CS_RTL`, by default the sibling checkout `..\computerspace\rtl`.

## Source

| File | What |
|---|---|
| `computerspace.asm` | frame loop, drawing (stars, objects, missiles, digits) |
| `game.asm` | the rules: game flow, missiles, collisions, explosions, scores, timer |
| `sound.asm` | the PSG sounds |
| `*.inc` | generated by `tools/` (committed, so the build needs no Python) |

Regenerate everything:

```
cd tools
python rocketgen.py ../rocket.inc
python saucergen.py ../saucer.inc --anchor=6
python postab.py ../postab.inc
python tables.py ../tables.inc
python digits.py ../digits.inc
python optstars.py ../stars_a.inc 350 --half=0
python optstars.py ../stars_b.inc 350 --half=1
```

## Notes

- After `Reset0Ref` the integrators stay held at zero (VIA PCR `$CC`) until a `Moveto`; `Draw_VLc`
  does not release them, so a list drawn straight after `Reset0Ref` collapses to a dot. Move first
  (`ldd #0` / `jsr Moveto_d`).
- `VECTREX.I` is the Vectrex BIOS include (Bruce Tomlin, changed by Malban).
